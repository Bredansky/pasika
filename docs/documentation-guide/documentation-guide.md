# Documentation Guide

This guide explains how to create Guides, Rules, Policies, and References in this repository.

## How To Create a Document

Run this whenever you add a new Guide, Rule, Policy, or Reference to the repository.

1. Pick the document kind from the [Glossary Reference](references/glossary-reference.md) so you know the right template.
2. Follow the [Template Usage Rule](rules/template-usage-rule.md) so the document has no leftover bracketed prompts.
3. For a Guide, follow the [Guide Creation Rule](rules/guide-creation-rule.md) so the Guide has the correct shape, naming, and folder layout.
4. For a Rule, follow the [Rule Creation Rule](rules/rule-creation-rule.md) so the Rule has the correct shape, naming, and vocabulary.
5. For a Policy, follow the [Policy Creation Rule](rules/policy-creation-rule.md) so the Policy collects repo-wide requirements without turning into a Rule.
6. For a Reference, follow the [Reference Creation Rule](rules/reference-creation-rule.md) so the Reference has the correct shape, naming, and folder layout.
7. Pick each requirement's keyword from the [RFC 2119](https://datatracker.ietf.org/doc/html/rfc2119) vocabulary so its strength matches what the requirement actually demands.
