# Documentation Guide

This guide explains how to create Guides, Rules, Policy documents, and References in this repository.

## How To Create a Document

Run this whenever you add a new doc to the repository.

1. Pick the document kind from the [Documentation Types Reference](references/documentation-types-reference.md) so you know the right template.
2. Follow the [Template Usage Rule](rules/template-usage-rule.md) so the doc has no leftover bracketed prompts.
3. For a Guide, follow the [Guide Creation Rule](rules/guide-creation-rule.md) so the doc has the correct shape, naming, and folder layout.
4. For a Rule, follow the [Rule Creation Rule](rules/rule-creation-rule.md) so the doc has the correct shape, naming, and vocabulary.
5. For a Policy document, follow the [Policy Creation Rule](rules/policy-creation-rule.md) so the doc collects repo-wide requirements without turning into a Rule.
6. For a Reference, follow the [Reference Creation Rule](rules/reference-creation-rule.md) so the doc has the correct shape, naming, and folder layout.
7. Pick each requirement's keyword from the [Requirement Vocabulary Reference](references/requirement-vocabulary-reference.md) so its strength matches what the requirement actually demands.
