# Rule Vocabulary Rule

Rule documents need precise enforcement language. Without a shared vocabulary, readers cannot tell which statements are required, forbidden, recommended, or optional.

- Rule bodies MUST use [RFC 2119 vocabulary](https://datatracker.ietf.org/doc/html/rfc2119): `MUST`, `MUST NOT`, `SHOULD`, `SHOULD NOT`, or `MAY`.
- `MUST` MUST mean required.
- `MUST NOT` MUST mean forbidden.
- `SHOULD` MUST mean recommended, with exceptions possible.
- `SHOULD NOT` MUST mean discouraged, with exceptions possible.
- `MAY` MUST mean optional.
- Rule-force prose in rule bodies MUST NOT use lower-case variants of these words.
- Guide and Reference documents MUST NOT use uppercase requirement words to state rules.
