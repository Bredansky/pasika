# Template Usage Rule

Authoring without a template makes every doc invent its own title, orientation, and section shape. This rule keeps new docs predictable.

This rule applies to Markdown documentation authored or maintained in this repository. Imported third-party docs are exempt unless they are rewritten into repo documentation.

- A new doc MUST pick its document kind from the [Documentation Types Reference](../references/documentation-types-reference.md) and start from the linked template for that kind.
- Authors MUST replace each bracketed prompt with the final title, explanation, step, or lookup content it asks for.
- Authors MUST delete template branches that do not apply to the document being written.
- Committed docs MUST NOT contain leftover bracketed prompts.
