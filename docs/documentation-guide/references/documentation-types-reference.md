# Documentation Types Reference

This reference helps authors look up the three Markdown document kinds in this repository. It matters because authors and reviewers can pick a document kind by intent and trust the layout without inventing new shapes for each directory.

| Kind      | Shape                                                                                           | Template                                         |
| --------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Guide     | A workflow-oriented document with one or more `## How To [...]` sections.                       | [Guide template](../_templates/guide.md)         |
| Rule      | An opinionated project rule that states required, forbidden, recommended, or optional behavior. | [Rule template](../_templates/rule.md)           |
| Reference | Lookup material such as a table, hierarchy, configuration block, glossary, or catalog.          | [Reference template](../_templates/reference.md) |
