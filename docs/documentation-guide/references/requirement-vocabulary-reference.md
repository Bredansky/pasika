# Requirement Vocabulary Reference

Use this reference to look up the strength each [RFC 2119](https://datatracker.ietf.org/doc/html/rfc2119) keyword carries in this repository's documents.

| Keyword      | Strength                             |
| ------------ | ------------------------------------ |
| `MUST`       | Required, no exceptions              |
| `MUST NOT`   | Forbidden, no exceptions             |
| `SHOULD`     | Recommended, exceptions possible     |
| `SHOULD NOT` | Discouraged, exceptions possible     |
| `MAY`        | Optional, either choice is acceptable |
